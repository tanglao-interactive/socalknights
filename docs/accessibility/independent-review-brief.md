# Independent review brief

Request a bounded review of the completed self-assessment rather than certification.

The reviewer should:

1. Review the declared scope, issue log, automated test design, manual matrix, and final report.
2. Sample the home, councils, events, and 404 experiences.
3. Test representative flows with NVDA and current Chrome on Windows.
4. Identify unsupported conclusions, remaining WCAG 2.1 A/AA failures, and third-party limitations.
5. Review the exact proposal language for accuracy.

Record the reviewer’s name/company, qualifications, dates, pages and assistive-technology versions tested, findings, retest outcome, and written permission to describe the review. If this review is not completed, retain “self-assessment” language only.
